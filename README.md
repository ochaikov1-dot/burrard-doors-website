# Burrard Doors - burrarddoors.ca

> Complete website codebase, high-resolution photography assets, and belt-drive openers catalog for **Burrard Doors** serving Metro Vancouver & Lower Mainland.

## 🚀 Quick Start for Claude / Developers

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Local Development**:
   ```bash
   npm run dev
   ```

3. **Build for Production / Hosting**:
   ```bash
   npm run build
   ```
   Output folder: `dist/` (Upload directly to your cPanel public_html, Vercel, Netlify, or Apache/Nginx web server).

---

## 🛠️ Project Contents

- **`src/data/openers.ts`** & **`openers_catalog.json`**: LiftMaster 8550W Elite, 6690L Smart Video, 8355W, GDD800, Marantec Synergy models, horsepower selection guide, and acoustic noise comparisons.
- **`src/data/assets.ts`** & **`assets_manifest.json`**: Verified photography catalog with Vancouver SEO alt tags.
- **`public/images/`**: Full binary high-resolution photography suite.
- **Quote Form**: Configured to forward quote inquiries to `mgow604@gmail.com`.
